# Swirlverse automation

Engine, episodes and run notes for the Swirlverse YouTube channel's automatic uploads.
- `DAILY_RUN.md`: the playbook every scheduled run follows
- `STRATEGY.md`: what performs, plus the experiment log
- `history.json`: every upload, used to avoid repeat topics
- `engine/`: shortkit (Shorts), longkit (long videos), voice, music and mix, thumbkit, qa
- `episodes/`: one python file per video
- `examples/`: full reference scenes from earlier episodes
- `ready/`: finished videos waiting for their slot (deleted after upload)
